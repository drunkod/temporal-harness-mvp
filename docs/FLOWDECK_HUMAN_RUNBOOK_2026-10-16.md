# Flowdeck operator entrypoint

The old dated pilot instructions have been replaced by [Manual testing on your MacBook](operations/manual-mac-testing/README.md).

Start with [00 — Prepare the Mac](operations/manual-mac-testing/00-prepare-mac.md), then follow the order in that index. Each stage has its own Markdown file, commands, expected results and troubleshooting. There are no repeated conversational confirmation steps.

Use a fresh configured project, not a historical pilot ID. After the first manual Send, the existing attended launcher can automatically continue P1 and start P2: those stages are observations in the same run, not separate launches.

Automatic initial Send remains a separate implementation gate described in [stage 04](operations/manual-mac-testing/04-automatic-initial-send.md). For the development objective, use the [MVP plan](plans/FLOWDECK_AUTONOMOUS_MVP_PROGRAMMER_GUIDE.md).

This small file preserves the established link destination; it is not a second runbook.
